**Device Information:**

**Security Information:**

We do NOT collect:

## 4. Data Storage and Security

### 4.1 Local Storage
**Primary Data Storage:**
- Your financial data is primarily stored locally on your device
- Data is encrypted using AES-256 encryption before storage
- Encryption keys are stored securely in your device's keychain/keystore

**Security Measures:**
- All sensitive data is encrypted at rest
- Database queries use parameterized statements
- Local storage includes data integrity verification

### 4.2 Cloud Storage (Optional)
If you enable cloud backup:
- Encrypted data may be stored in secure cloud infrastructure
- Data remains encrypted during transmission and storage
- We use industry-standard cloud security practices
- You can disable cloud backup at any time

### 4.3 Data Transmission
When data is transmitted:
- All communications use HTTPS/TLS encryption
- API calls are authenticated and authorized
- Data is encrypted before transmission
- We implement certificate pinning for additional security

### 4.4 Security Measures
We implement multiple layers of security:
- End-to-end encryption for sensitive financial data
- Secure authentication and session management
- Regular security assessments and updates
- Incident response and breach notification procedures
